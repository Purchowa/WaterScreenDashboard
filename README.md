# Water Screen Dashboard

The **Water Screen Dashboard** is a web-based application designed to manage and monitor the **Water Screen System**. It consists of two main components:

- **Backend** - A REST API server that handles communication between the water curtain controller and the frontend.
- **Frontend** - A control panel that provides a user-friendly interface for managing the water curtain settings and monitoring its status.

## General Features

- **Backend:**
  - REST API for communication with the water curtain controller.
  - Handles configuration, logging, and data retrieval.
  - Uses authentication mechanisms.

- **Frontend:**
  - Intuitive UI for managing water curtain operations.
  - Displays real-time status and analytics.
  - Supports configuration of presentation modes and schedules.
